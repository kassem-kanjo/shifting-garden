# Changelog

## 0.1.0 · 2026-10-19
- First version: four woodblock scenes in a sliding puzzle that breathes apart and back together.
- Exact countdown to the whole picture, in pixel digits on a label at the bottom.
- Ten glitch effects, including guest blocks from the other scenes.
- Screenprint treatment of the Midjourney scenes (flat inks, crisp keylines).
- macOS screensaver (universal, macOS 12+), built with the Command Line Tools only.
